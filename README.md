# Project Management App

A simple Project Management App built with **React** and **Tailwind CSS** as part of my React learning journey.

The project focuses on practicing React fundamentals by building a user interface for creating projects, viewing project details, and managing tasks.

## Features

- Create and delete projects
- Select projects and view their details
- Add and delete tasks
- Display an empty state when no project is selected
- Display project information, including title, description, and due date

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Vite

## React Concepts Practiced

- Functional Components and Props
- `useState` for state management
- Passing event handlers between components
- Lifting State Up
- Conditional Rendering
- Rendering Lists with `map()`
- Handling Forms and User Input
- Component Composition

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <https://github.com/AhmedElazab1/Project-Management-APP.git>
   ```

2. Navigate to the project directory:

   ```bash
   cd <01-starting-project>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

This project is part of my hands-on practice while learning React. It helps reinforce the fundamentals of component-based development, state management, and building interactive user interfaces.
